# الهيئة السورية للاختصاصات الطبية
## مفاضلة التسجيل المباشر 2025-2026

نظام ويب متكامل لتقديم طلبات مفاضلة التسجيل المباشر للبورد السوري، مبني بـ Next.js 16 + Prisma + PostgreSQL.

## ✅ جاهز للنشر على Render بدون أي إعداد!

المشروع يستخدم **PostgreSQL** كقاعدة البيانات. عند الرفع على Render عبر `render.yaml`، سيتم إنشاء قاعدة البيانات تلقائياً.

## المميزات

- 🎨 **تصميم حديث** (glassmorphism + framer-motion + tailwind 4)
- 🔒 **إخفاء أعداد الشواغر** — تُرسل فقط كحالة "متاح/غير متاح"
- 🚫 **منع تكرار الرقم الوطني** — تحقق فوري ومضاعف على الخادم
- 📋 **الوثائق المطلوبة كتعداد** — لا checkboxes، فقط قائمة وزر متابعة
- 👨‍⚕️ **منطق طبيب البورد السوري** — رغبة واحدة للأطفال الخدج + معدل البورد
- 🖨️ **طباعة A4** مع علامات ✓ بجانب كل وثيقة
- 📊 **لوحة إدارة** محمية + تصدير CSV
- 🌐 **قابل للنشر على أي استضافة** (Render, Railway, Vercel, Netlify, Docker)

## النشر على Render (الأسهل)

1. ارفع المشروع إلى GitHub
2. على Render: **New + → Blueprint** → اختر المستودع
3. سيُنشئ Render كل شيء تلقائياً (PostgreSQL + التطبيق)

راجع [DEPLOYMENT-GUIDE.md](./DEPLOYMENT-GUIDE.md) للتفاصيل.
